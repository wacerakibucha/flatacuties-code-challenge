# 🐾 Flatacuties Code Challenge

This is the **Phase 1 Week 2 Code Challenge** project for Moringa School.  
Flatacuties is a simple web application where users can view a list of animals and vote for the cutest one.

---

## 📌 Learning Goals
- Practice **Array Iteration**
- Work with the **DOM (Document Object Model)**
- Handle **Events**
- Communicate with a **local JSON server**

---

## 🚀 Features
- Display a list of all animal names
- Click on an animal’s name to view its:
  - 🖼️ Image
  - 🗳️ Current number of votes
- Increment votes by clicking the **Vote** button
- Reset votes back to **0** using the **Reset** button

---

## 📂 Project Structure
flatacuties-code-challenge/
│── index.html # Main HTML file
│── style.css # Styling
│── script.js # JavaScript logic (fetch, DOM, events)
│── db.json # Local backend (JSON Server)

## ⚙️ Setup Instructions

### 1. Clone the repository
```bash
git clone https://github.com/wacerakibucha/flatacuties-code-challenge.git
cd flatacuties-code-challenge

2. Install JSON Server (if not installed already)
npm install -g json-server

3. Start the backend
json-server --watch db.json


The server will run at:
👉 http://localhost:3000/characters

4. Open the app

Simply open index.html in your browser.
